## Start with work you already do

Choose something small and familiar: turn notes into a checklist, improve a draft, prepare an agenda or write a reply. Use a fictional example for the first attempt.

<Steps>
  <Step title="Describe the outcome">What should the finished result help you do? Bring an example of a good result and explain what needs checking.</Step>
  <Step title="Choose a tool together">We can help you compare suitable tools and account options. You own the account and enter your own credentials and payment details.</Step>
  <Step title="Practise the task">Explain the context, ask for a useful format and try a follow-up. Review the output against the facts you provided.</Step>
  <Step title="Keep a repeatable method">Save the prompt, checks and next steps in your take-away guide. Use the agreed setup-question window if something is unclear after handover.</Step>
</Steps>

## What to bring

- A task you would like help with and a device you normally use.
- Access to your own account, if you already have one.
- A fictional or sanitised example, plus anything the result must get right.
- Questions about cost, privacy, accessibility or confidence using AI.

Never email passwords, payment details or API keys.

## What happens next

The one-person setup and coaching package includes tool choice, guided setup, practical coaching, a take-away user guide and 14 days of setup questions. [See scope and fees](/account/account-and-billing).

If a task calls for connected tools or a custom build, we agree its scope, access, testing and price separately before work starts. [How Vivacity works](/getting-started/how-vivacity-works) explains the options.
