## A useful pattern

> I need to [task] for [audience]. Use these facts: [approved information]. Keep [constraints]. Return [format]. Ask about missing information rather than inventing it.

## A fictional example

> I run a fictional mobile dog-grooming business. Draft a friendly reply to a first enquiry. Ask for the suburb, dog size and preferred day. Do not invent prices or confirm availability. Keep it under 100 words and finish with a clear question.

## Improve the result

- Ask for a shorter or clearer version.
- Point out an error and supply the correct fact.
- Ask it to list assumptions and unanswered questions.
- Compare the draft with the source before using it.

## When numbers are involved

Name the period, units and calculation you want. Ask for the workings and verify them yourself. A tool can propose possible explanations, but those are hypotheses until the evidence supports them.
