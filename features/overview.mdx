Choose an exercise that matches something you already understand. Use fictional or sanitised information, then check the result yourself.

<CardGroup cols={2}>
  <Card title="Draft and improve" icon="pen">Turn a rough note into an email, a checklist or a first draft. Supply the facts and check the wording.</Card>
  <Card title="Make information clearer" icon="file-lines">Ask for a plain-English explanation or summary. Compare it with the original and check omissions.</Card>
  <Card title="Prepare for a decision" icon="scale-balanced">List options, assumptions and questions to investigate. Confirm the evidence before choosing.</Card>
  <Card title="Build a useful routine" icon="list-check" href="/features/daily-briefing">Use a short, repeatable check-in with information you choose.</Card>
</CardGroup>

## When a workflow may help

If the same task repeats and a manual approach is becoming awkward, a scoped automation may be worth exploring. Define the trigger, inputs, intended result, review point and what should happen if it fails.

A tool name in these guides does not mean a ready-made Vivacity integration is available. We check suitability, access and testing for the specific task.
