## What is a skill?

A skill packages instructions and, sometimes, supporting files or scripts so an AI assistant can follow a repeatable method. For example, a writing skill could explain your tone, the facts it may use and the checks needed before a draft is finished.

A skill is useful only when its instructions fit your task and the assistant can use it. Review its files and any actions it can run before installing it.

## What is MCP?

Model Context Protocol, or MCP, is a way for an AI application to connect to tools and information through a server. A server may expose capabilities such as finding a document or preparing an action. It is not itself permission to use every capability.

Before connecting one, understand who runs it, what it can access, which actions it exposes and how authentication and cost work. The actual permissions and review settings matter more than the connector's name.

## A practical example

You could start with a writing skill and a fictional enquiry to prepare a reply. If the task later needs an inbox connection, that is a separate access and testing decision. The skill does not create consent to read or send real messages.

## Questions to ask

- Does this help a task I already understand?
- What information can it read and what can it change?
- Who provides it and how do I remove access?
- What will I review before using the output?

For the protocol itself, see the [official MCP introduction](https://modelcontextprotocol.io/docs/getting-started/intro). For a business task, [start with the smallest useful example](/getting-started/quickstart).
